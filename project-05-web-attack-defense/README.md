# Project 5 — Web Application Attack & Defense

## Overview

A controlled web-security lab focused on understanding common web application attacks and applying defensive controls.

## Objectives

- Identify common web application weaknesses.
- Perform controlled security testing.
- Analyze the impact of successful attacks.
- Apply defensive controls.
- Re-test the environment after remediation.

## Lab Approach

The project used intentionally vulnerable web applications and controlled attack techniques to demonstrate how application weaknesses can be identified and addressed.

## Assessment Workflow

1. Configure the vulnerable web application.
2. Perform controlled security testing.
3. Identify vulnerable functionality.
4. Document successful attack conditions.
5. Apply defensive controls.
6. Re-test the application.
7. Document the results.

## Security Lessons

Web application security requires both identifying exploitable weaknesses and implementing effective defensive controls. Testing and re-testing help verify whether remediation measures are effective.

## Scope

All testing was performed against intentionally vulnerable systems in a controlled environment.
