Security incident report

Section 1: Identify the network protocol involved in the incident

The network protocol involved in this incident is SSH (Secure Shell) Port 22.



Section 2: Document the incident
A simulated brute force and reconnaissance attack was conducted in a controlled lab environment. The attacker machine (Kali Linux - 172.20.10.9) targeted a Cowrie SSH honeypot deployed on Ubuntu (172.20.10.7).




Section 3: Recommend one remediation for brute force attacks
 Implement Fail2Ban with SSH Rate Limiting
