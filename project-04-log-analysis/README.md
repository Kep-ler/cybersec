# Project 4 — Log Analysis & Attack Detection

## Overview

A hands-on security monitoring project focused on analyzing system and security logs to identify suspicious activity and support attack detection.

## Objectives

- Collect and examine security-relevant logs.
- Identify indicators of suspicious activity.
- Analyze attack patterns.
- Correlate relevant events.
- Document findings and defensive recommendations.

## Investigation Workflow

1. Collect relevant log data.
2. Establish a baseline of expected activity.
3. Identify unusual authentication or network events.
4. Investigate suspicious activity.
5. Correlate related events.
6. Document findings.
7. Recommend defensive improvements.

## Security Lessons

Effective log analysis can provide visibility into authentication activity, reconnaissance, attack attempts, and other indicators of compromise.
